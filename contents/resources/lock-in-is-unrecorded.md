# The Unchosen Log

**From the episode:** *Lock-in is a record-keeping failure.*

Nobody decides to lock in. It builds up one convenient default at a time — none of them written down. This log is where they get written down, so a future migration is a reading exercise instead of an excavation.

**What it is:** a running list of the alternatives your team passed on.
**Who fills it in:** whoever just took a default. Any level. No meeting needed.
**Time per entry:** under two minutes.

## How to use it

1. **Catch the moment.** Your team just accepted a vendor's default — the built-in queue, the identity system, the storage format. That moment is the trigger.
2. **Add one line to the table below.** What you took, what you passed on, why, and who decided. Write it the way you would say it out loud.
3. **Keep the log where your design docs already live.** Not a new tool — a page your team already opens.

That is the whole practice. One line, at the moment of the decision.

## The log

| Date | We took | We did not take | Because | Who decided |
|---|---|---|---|---|
| *(example)* | *vendor's managed queue* | *running our own broker* | *ships this sprint; nobody free to run a broker* | *the platform lead* |
| | | | | |
| | | | | |

The first row is an example — replace it with your own.

**What goes in each column:**

- **We took** — the thing you chose, named plainly.
- **We did not take** — the alternative you skipped. If there were several, write the one you would have chosen instead.
- **Because** — the honest reason, in one phrase. "It was the default" is a valid entry. So is "deadline".
- **Who decided** — a name, not a team. Not for blame — so the future reader knows who to ask.

## Three rules that keep it useful

1. One line at decision time beats a paragraph at migration time. If an entry takes more than two minutes, you are writing too much.
2. Never skip an entry because the reason feels weak. A weak reason, recorded, is still a recorded decision.
3. Do not tidy the log later. It is evidence, not a report.

## What this buys you

When the pricing changes or the vendor stumbles, your team reads this log and prices the exit in an afternoon — because every question a migration quote would bill you to answer is already answered here, in your own words.
